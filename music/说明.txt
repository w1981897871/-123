把音乐文件放在本文件夹中，网站会随机选一首循环播放。

## 使用步骤

1. 通过**合法渠道**获取音乐文件（例如：网易云音乐 / QQ音乐 购买或下载后转存为 MP3，或使用你已有的正版文件）。
2. 将文件放到本文件夹（music/）中，例如：
   - `暧昧.mp3`
   - `演员.mp3`
   - `你还要我怎样.mp3`
3. 打开网站根目录的 `site-config.js`，在 `music.files` 里把文件名逐行写上：
   ```js
   music: {
       files: ["暧昧.mp3", "演员.mp3"],
       random: true,   // true=随机选歌 false=按顺序
       loopIntro: false, // false=整曲循环 true=只循环前奏
       volume: 0.7
   }
   ```
4. 刷新网页：随机播放其中一首并整曲循环；点播放器上的 ⏭ 随机切歌。

## 也可以直接在网站上改

打开网站 → 点右上角 ✏️ 按钮 → "⑥ 背景音乐" 里修改音乐列表 → 保存。

注意：浏览器安全策略会拦截"无用户操作的自动播放"。
首次打开时若没有声音，页面顶部会出现提示条，点击页面任意位置即可播放。
