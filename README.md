# 🌇 夕阳西下，煮一碗清粥 · 个人网站

一个纯静态、零依赖的深色现代风个人网站，双击即可打开，无需安装任何东西。

## ✨ 功能特性

- **深色现代风**：渐变强调色 + 玻璃拟态导航 + 网格/光晕背景
- **背景音乐**：打开网页自动播放薛之谦《暧昧》**整曲循环**，悬浮唱片播放器 + 键盘 `M` 快捷键
- **打字机效果**：首页身份描述自动轮播
- **代码卡片**：首页右侧的趣味代码窗口（纯 CSS 实现）
- **生活随笔**：记录黄昏、清粥与生活美好的诗意文字区块
- **滚动动画**：区块进入视口时淡入上移，技能条自动填充
- **导航联动**：滚动时自动高亮当前所在章节
- **移动端适配**：汉堡菜单、响应式布局
- **真实表单**：联系表单已接入 Web3Forms，填好 Access Key 即可收到留言
- **SEO 优化**：Open Graph 分享标签 + 结构化数据（JSON-LD）
- **细节功能**：顶部滚动进度条、返回顶部按钮、表单校验提示、页脚年份自动更新

## 🚀 使用方法

### 本地预览

- 直接双击 `index.html` 即可在浏览器中打开。
- 或启动一个本地静态服务器（推荐，避免个别浏览器对 `file://` 的限制）：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .

# 然后访问 http://localhost:8080
```

### 部署上线（任选其一）

- **GitHub Pages**：把本文件夹推送到仓库，在仓库 Settings → Pages 中选择部署分支。
- **Vercel / Netlify**：直接拖拽本文件夹到对应官网即可完成部署。
- **自有服务器**：将整个文件夹上传到网站根目录即可。

## 🎵 背景音乐（薛之谦《暧昧》整曲循环）

网站会在打开时自动播放《暧昧》，从开头播到结尾后自动从头再来，**一直循环播放**。

### 放置音频文件（必需）

1. 通过**合法渠道**获取《暧昧》的音频文件（网易云音乐 / QQ音乐 购买下载后转存为 MP3，或使用你已有的正版文件）。
2. 将文件命名为 `暧昧.mp3`，放入 `music/` 文件夹（即 `music/暧昧.mp3`）。
3. 刷新网页即可听到《暧昧》整曲循环播放。

### 播放器使用

- 左下角**悬浮唱片按钮**：点击播放 / 暂停，播放时唱片旋转
- 页面顶部提示条（自动播放被浏览器拦截时出现）：点击页面任意位置即可播放
- 键盘快捷键：按 **`M`** 播放 / 暂停
- 移动端：仅显示圆形按钮，信息条自动隐藏

### 循环配置

打开 `script.js`，找到 `MUSIC` 配置：

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `SRC` | 音频文件路径 | `music/暧昧.mp3` |
| `INTRO_END` | 仅当前奏循环模式（`LOOP_INTRO: true`）时生效 | `30` |
| `LOOP_INTRO` | `false` 整曲循环（默认）/ `true` 只循环前奏 | `false` |
| `VOLUME` | 音量（0 ~ 1） | `0.7` |

> 关于自动播放：浏览器安全策略会拦截"无用户操作的自动播放"。首次访问时若没有声音，
> 页面顶部会出现"点击页面任意位置播放"的提示条，点击后即可播放（业界标准做法）；
> 之后再次访问时，大多数浏览器会允许直接自动播放。
> 另外请通过本地服务器或部署后的网址访问，个别浏览器会限制 `file://` 下的音频加载。

## ✏️ 如何改成你自己的内容

所有内容都在 `index.html` 中，用任意文本编辑器打开，搜索并替换以下内容：

| 位置 | 要改什么 |
| --- | --- |
| `<title>` 与 `<meta name="description">` | 网站标题与描述 |
| `.logo` / `.hero-name` | 你的名字或昵称 |
| `#about` 段落与 `.about-facts` | 你的自我介绍、个人信息 |
| `#skills` 的百分比 `data-width` | 你的技能熟练度（0% ~ 100%） |
| `#life` 的随笔句子 | 换成你自己喜欢的文字 |
| 社交链接 `href`（GitHub / 掘金 / CSDN / 邮箱） | 换成你的真实主页地址 |
| `.contact-item` 中的邮箱 | 你的联系邮箱 |

配色调整：打开 `styles.css`，修改开头的 `:root` 变量即可，比如

```css
:root {
    --primary: #6366f1;   /* 主色（靛蓝） */
    --primary-2: #8b5cf6; /* 辅色（紫） */
    --accent: #22d3ee;    /* 强调色（青） */
}
```

## 📬 关于联系表单（Web3Forms 真实发送）

网站已接入 **Web3Forms**，访客提交表单后消息会直接发到你的邮箱，无需自己搭后端。

### 启用步骤（约 1 分钟）

1. 打开 <https://web3forms.com>，输入你的邮箱，点击 **"Create Access Key"**。
2. 去邮箱点击确认链接，页面会显示一串 **Access Key**（形如 `1a2b3c4d-...`），复制它。
3. 打开 `script.js`，在文件顶部的 `FORM_CONFIG` 中，把 Key 粘贴到 `ACCESS_KEY`：

   ```js
   const FORM_CONFIG = {
       ENDPOINT: 'https://api.web3forms.com/submit',
       ACCESS_KEY: '在这里粘贴你的 Access Key',
   };
   ```

4. 保存后刷新页面，提交一次表单测试，即可在邮箱收到消息。

> 说明：
> - 免费版每月可接收 **250 封** 消息，个人站完全够用。
> - 建议通过本地服务器（`python -m http.server 8080`）或部署到线上后再测试，个别浏览器会限制 `file://` 下的跨域请求。
> - **重要**：免费版只接受来自浏览器（客户端）的提交，会拦截服务器/数据中心 IP 发起的请求。所以用 `curl`、脚本或服务器端测试会返回 403，属正常现象，不代表 Key 无效——请直接在浏览器里打开站点提交表单验证。
> - 若想换用 Formspree / EmailJS 等服务，只需修改 `FORM_CONFIG.ENDPOINT` 与请求体的字段格式。
