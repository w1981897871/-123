# 🌇 夕阳西下，煮一碗清粥 · 个人网站

一个纯静态、零依赖的深色现代风个人网站，双击即可打开，无需安装任何东西。

## ✨ 功能特性

- **首页流水灯轮播**：自动从 `images/` 文件夹选取照片，无缝滚动播放（悬停暂停）；加照片后双击 `update-images.bat` 即自动更新
- **随笔随机轮播**：生活随笔大引言每 20 秒随机播放一条（含所有随笔，悬停暂停），输入的所有随笔都会保存并参与轮播
- **作者编辑权限**：只有作者能编辑——访客看不到 ✏️ 按钮，访问 `网站地址?edit` 后输入密码才能进入编辑（密码只存哈希）
- **随机音乐**：把音乐放进 `music/` 文件夹、在配置里列个文件名，网站自动随机选歌整曲循环；播放器带 ⏭ 随机切歌
- **深色/浅色主题切换**：导航栏 ☀️/🌙 按钮一键切换，记忆你的选择，默认跟随系统
- **访问统计**：页脚显示访客数与访问量（不蒜子，免费）
- **留言区**：随笔下方可开启 giscus 评论区（访客留言存到你的 GitHub Discussions）
- **深色现代风**：渐变强调色 + 玻璃拟态导航 + 网格/光晕背景
- **打字机效果**：首页身份描述自动轮播
- **生活随笔**：记录黄昏、清粥与生活美好的诗意文字区块
- **滚动动画**：区块进入视口时淡入上移，技能条自动填充
- **导航联动**：滚动时自动高亮当前所在章节
- **移动端适配**：汉堡菜单、响应式布局
- **真实表单**：联系表单已接入 Web3Forms，消息直达邮箱
- **SEO 优化**：Open Graph 分享标签 + 结构化数据（JSON-LD）
- **细节功能**：顶部滚动进度条、返回顶部按钮、键盘 M 播放/暂停、页脚年份自动更新

## 🖼️ 首页图片轮播（自动从 images/ 文件夹选图）

首页右侧以"流水灯"效果无缝滚动播放 `images/` 文件夹里的照片（鼠标悬停暂停）。

### 使用步骤

1. 把你的照片（建议 16:10 横图）放进 `images/` 文件夹（支持 jpg/png/webp/gif/svg）
2. **双击运行 `update-images.bat`**（自动扫描文件夹并生成清单，约 1 秒）
3. 刷新网页，照片自动开始流水灯轮播

> 以后加图/删图：更新 images/ 文件夹后，再双击一次 `update-images.bat` 即可。
> 如果不想用自动扫描，也可以在 `site-config.js` 的 `heroImages` 里手动指定图片或图片网址。

## 🎵 背景音乐：随机选歌循环播放1. 把音乐文件（**合法渠道**获取）放进 `music/` 文件夹，例如：
   ```
   music/暧昧.mp3
   music/演员.mp3
   music/你还要我怎样.mp3
   ```
2. 打开 `site-config.js`，在 `music.files` 里把文件名逐行写上：
   ```js
   music: {
       files: ["暧昧.mp3", "演员.mp3", "你还要我怎样.mp3"],
       random: true,      // true=随机选歌 false=按顺序
       loopIntro: false,  // false=整曲循环 true=只循环前奏
       volume: 0.7
   }
   ```
3. 刷新页面：随机播放其中一首，整曲循环；点播放器上的 **⏭** 随机切歌。
   （播放器标题会显示当前歌名；某首歌文件缺失时自动跳到下一首）

### 修改编辑密码

1. 打开命令行（Win+R → 输入 cmd → 回车），进入网站文件夹：

## 🌐 绑定自定义域名（提升专业形象，约 15 分钟）

把 `w1981897871.github.io/-123/` 变成 `www.你的名字.com`：

### 1. 买域名
任意域名商（阿里云/腾讯云/Namesilo 等）购买一个域名，如 `xiyangxia.com`（约 50~100 元/年）。

### 2. 添加 DNS 记录（在你的域名商后台）
| 类型 | 主机记录 | 值 |
| --- | --- | --- |
| CNAME | `www` | `w1981897871.github.io` |
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |

### 3. GitHub 绑定
1. 仓库 → **Settings** → **Pages**
2. **Custom domain** 输入你的域名（如 `www.xiyangxia.com`）→ **Save**
3. 勾选 **Enforce HTTPS**（等几分钟生效，出现绿色锁即可）

### 4. 创建 CNAME 文件（可选但推荐）
在网站根目录新建文件 `CNAME`（无扩展名），内容只写一行你的域名：
```
www.xiyangxia.com
```
上传到 GitHub 后，即使以后改仓库名域名也不失效。

> 提示：免费域名也可用 `.eu.org`、`.tk` 等，绑定流程相同。

## 💬 开启留言区（giscus，约 3 分钟）

1. 打开你的 GitHub 仓库 → **Settings** → 左侧 **General** → 滚动到 **Discussions** → 勾选 **Set up discussions** → 初始化一个分类（如 Announcements）
2. 打开 <https://giscus.app/zh-CN>，在"仓库"输入框填 `你的用户名/仓库名`（如 `w1981897871/-123`）→ 点 **启用 giscus**
3. 按页面提示完成配置（会引导你在仓库安装 giscus app 并选择分类），页面会生成一段代码
4. 从生成代码里复制四个值：`data-repo`、`data-repo-id`、`data-category`、`data-category-id`
5. 打开 `site-config.js`，填入 `giscus` 配置并改 `enabled: true`：
   ```js
   giscus: {
       enabled: true,
       repo: "w1981897871/-123",
       repoId: "R_xxx",
       category: "Announcements",
       categoryId: "DIC_xxx"
   },
   ```
6. 重新上传 `site-config.js`（或在网站 `?edit` 面板保存一次同步云端），留言区即可使用

> 访客的留言会以 Discussion 的形式出现在你的仓库 Discussions 里，完全免费、无需自建后端。
